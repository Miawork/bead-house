# 拼豆小屋 V2.1｜咖啡角与成品工坊

正式游玩：https://bead-house-production.up.railway.app

本版基于 V2.0 单人原型，修复桌面镜头太远、取豆笔与抽屉重叠、画板尺寸外观几乎不变的问题。

## 已修改

- 坐下后自动切换接近垂直的正视近景，并按屏幕比例和底板尺寸取景；桌面“⌖”按钮可随时回正，缩放和平移仍可自由调整。
- 六种画板（29×29、32×32、52×52、64×64、128×128、256×256）具有不同实体尺寸；从右侧抽屉取出才出现在桌面。
- 镊子放在前侧深色防滑工具垫；取豆笔在独立的青色笔座；豆盒排列在桌面右侧；装豆器居中靠前，避免互相遮挡。
- iPad 用于图库 / 上传参考图片；图片仅在 iPad 上显示，不自动摆豆。
- 保留 V2.0 取豆、装豆、关盖摇豆、装笔和逐颗放豆的交互行为。
- 咖啡角支持自己分步骤制作、请 NPC 小暖制作，或直接拿取现成饮品；拿起后直接点击画面中的杯子饮用，只有喝下时才提示剩余口数，坐下时也可以放到拼豆桌边并再次拿起。
- 拼完后可把当前底板带到独立熨烫间，选择自助或 NPC 代烫，并选择普通烫、毛巾烫、水晶烫、闪粉烫及融合程度。
- 熨烫完成后再选择钥匙扣、冰箱贴、画框、桌面摆件或胸针；成品可以挂到外墙或熨烫间墙面，也能空手取下后换墙、换位置重挂。
- 线上版本会把所有拼豆桌、每面墙的作品与取下状态、桌上饮料、手持物和个人制作进度存到私有云端存储；同一浏览器下次进入会自动恢复。

## 运行

运行 `npm install && npm start`，然后打开 http://localhost:8787。执行 `npm test` 可验证多人同步和持久化恢复。

## 局限

这不是百分之百的物理模拟。线上使用一个公共多人房间；个人身份目前是浏览器内的匿名 ID，清除网站数据或换浏览器后不会自动关联原来的个人进度。上传参考图仍只存本机。正式站运行在 Railway 新加坡区域，进度保存在持久化磁盘；原 Vercel 站保留为备站和旧存档迁移源。

请查看 `DEPLOY.md` 获取 Railway 自动部署、持久化磁盘和 Vercel 备站说明。
